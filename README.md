# ERP Agent UI

Design and specification files for **ERP Agent** — the CementOps attended-automation tool
(C# .NET WinForms + visible WebView2) that runs approved, signed scripts inside the employee's
own Oracle session.

## `designs/`

| File | What it is |
|------|------------|
| `ALL_Ways.html` | Options paper "من الميدان إلى أوراكل" — 8 write paths and 5 report paths from field to Oracle, with the recommendation and decision sheet. |
| `ERP_Agent.html` | Security review submission ADD-002 v2.0 — numbered, testable requirements (A–N), negative assurances, rejected alternatives, threat model, NCA/PDPL mapping, acceptance tests V1–V33, open items, phased rollout. |
| `ERP_Agent_UI.html` | Static UI mockups (ADD-002 v1.7) — window shell plus 16 screens (user, designer, studio, long-running jobs), script language draft, and open design decisions. |
| `App-designed.html` | Interactive, offline, bilingual (EN/AR) clickable prototype of the tool — simulated only, no real automation, network or credentials. |

All files are self-contained and open offline in a browser.
